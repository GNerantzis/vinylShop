# VinylShop

ASP.NET MVC web application for a fictional vinyl record shop.

## Overview

VinylShop is a web application built as part of my software development training.  
It simulates an online vinyl record store with pages for browsing vinyls, managing a cart, customer-related sections and basic user authentication.

## Features

- ASP.NET MVC web application structure
- Home, Vinyls, Cart, Customers, About and Contact pages
- User registration and login navigation
- Custom homepage layout for a fictional vinyl shop
- Static frontend assets and responsive web layout
- OWIN startup configuration
- ASP.NET application lifecycle setup

## Technologies

- C#
- ASP.NET MVC
- .NET Framework
- OWIN
- HTML
- CSS
- JavaScript
- Bootstrap
- NuGet
